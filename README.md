# Skill-and-You-se-perfectionner-en-HTML-CSS-3

Exercice : créer un site vitrine de 4 pages

# 📚 Librairie L'Indépendante

Site vitrine statique réalisé dans le cadre d'un entraînement en intégration web (HTML5 & CSS3). Ce projet présente une librairie fictive, ses valeurs, ses horaires, une sélection de coups de cœur littéraires ainsi que des citations philosophiques.

---

## 🎯 Objectifs pédagogiques

- Structurer un site multi-pages sémantique en **HTML5** (`<header>`, `<nav>`, `<main>`, `<blockquote>`, `<footer>`).
- Appliquer une charte graphique cohérente sur l'ensemble des pages via **CSS3** et des variables personnalisées (`:root`).
- Gérer la mise en page avec **Flexbox** (navigation horizontale, alignement de cartes livres, pied de page).
- Implémenter une navigation fluide avec gestion de l'état actif (`.active`) et des **ancres internes** (`:target`).

---
